Reasoning¶

Deliberation: pricing a menu’s contrasts and answering them. Pure math and a protocol — this layer imports nothing first-party.

Planner¶

class src.simulation.reasoning.planner.Signal(w, noise)[source]¶

Bases: object

Immutable object representing a single contrast question about \(Q\) on a menu, and the precision it is acquired at.

The oracle returns \(y = w^\top Q^*(X) + \eta\), \(\eta \sim N(0, \sigma^2)\), with \(\sigma^2 = \lambda\theta/(\lambda-\theta)\) set so that the posterior eigenvalue falls to the water level \(\theta\).

The weights are the eigenvectors \(\psi\) of the contrast matrix \(\tilde K = W^{1/2} P_W \Sigma P_W^\top W^{1/2}\), rescaled by cell measure, \(w = W^{1/2}\psi\); on a uniform mesh \(w \propto \psi\). Then \(\sum_j w_j Q_j \approx \int \phi\, Q\, \mathrm{d}c\) is mesh-invariant and \(\sum_j w_j = 0\).

Parameters:

  • w (np.ndarray) – Node weights, shape (N,); sum to zero.

  • noise (float) – Signal noise variance \(\sigma^2\).

solve(q, Sigma, areas)[source]¶

Joint solve for the temperature \(\delta\) and the water level \(\theta\).

\[f(\delta) = H\big(\text{softmax}(q/\delta)\big) - \ln\!\big(h\, V^{\text{post}}(\delta)\big), \qquad V^{\text{post}}(\delta) = \sum_i \min\{\theta(\delta), \tilde\lambda_i\},\]

where \(\theta(\delta)\) solves \(\delta/\kappa = \sum_i \min(1, \tilde\lambda_i/\theta)\).

Early exits: greedy (\(\delta = 0\)) when the floor cannot bind (h <= 0, V <= 0, or a floor already below the greedy entropy).

Parameters:

  • q (np.ndarray) – Prior (pre-reasoning) action values on the menu, shape (N,).

  • Sigma (np.ndarray) – Prior covariance on the menu, shape (N, N).

  • areas (np.ndarray) – Cell areas, shape (N,).

Returns:

Resulting decision, the chosen action probabilities.

Return type:

Decision
