Belief¶

This module contains implementation of Gaussian-Process learning for experience and reasoning agents, common kernel functions, and a module for computing prior means to initialize the GP.

Gaussian Process¶

Gaussian-Process over an action-value function Q.

This module implements a Gaussian-Process belief over an action-value function \(Q\). It provides all necessary functionality to maintain and update this belief as new observations are made.

We assume \(Q(\mathbf{X})\) follows a Gaussian process with mean function \(m(\mathbf{X})\) and covariance function \(K(\mathbf{X}, \mathbf{X}')\). Equivalently, the decision maker has a prior belief over \(Q\) characterized by these functions. \(Q(\mathbf{X}) \sim \mathcal{N}(m(\mathbf{X}), K(\mathbf{X}, \mathbf{X}))\)

By assumption, for any finite collection of points \(\mathbf{x}_1, \dots, \mathbf{x}_n\), the corresponding function values \(Q(\mathbf{x}_1), \dots, Q(\mathbf{x}_n)\) are jointly Gaussian. The GP posterior given a set of observations \(\mathbf{r}\) can be computed:

\[Q(\mathbf{X}_*) \mid \mathbf{r} \sim \mathcal{N}(\bar{m}(\mathbf{X}_*), \bar{K}(\mathbf{X}_*, \mathbf{X}_*))\]

where

\[\begin{split}\bar{m}(\mathbf{X}_*) &= m(\mathbf{X}_*) + K(\mathbf{X}_*, \mathbf{X}) [K(\mathbf{X}, \mathbf{X}) + \sigma_n^2 I]^{-1} (\mathbf{r} - m(\mathbf{X})) \\ \bar{K}(\mathbf{X}_*, \mathbf{X}_*) &= K(\mathbf{X}_*, \mathbf{X}_*) - K(\mathbf{X}_*, \mathbf{X}) [K(\mathbf{X}, \mathbf{X}) + \sigma_n^2 I]^{-1} K(\mathbf{X}, \mathbf{X}_*)\end{split}\]

\(\mathbf{X}_*\) denotes the query points at which we want to evaluate the posterior.

To generalize to any input signal, we consider linear functionals of the form \(r_i = \mathbf{w}_i^\top Q(\mathbf{X}_i) + \varepsilon_i\), where \(\varepsilon_i \sim \mathcal{N}(0, \sigma_i^2)\) is considered to be some independent Gaussian noise with variance \(\sigma_i^2\) and could plausibly be \(0\).

Note that a temporal-difference observation is a special case of this linear functional, with \(r_i = Q(\mathbf{x}_{\text{decision}}) - \gamma\, Q(\mathbf{x}_{\text{outcome}})\) and \(\varepsilon_i = 0\), \(\mathbf{x}_{\text{decision}}\) and \(\mathbf{x}_{\text{outcome}}\) are the decision and outcome vectors, \(\mathbf{w}_i = (1, -\gamma)\).

The vector \(\mathbf{r}\) reports the realized observations of the linear functionals. Collecting all known weight vectors and input points, let \(\mathbf{X}_A\) stack every input point. The linear system is then:

\[\mathbf{r} = W Q(\mathbf{X}_A) + \boldsymbol{\varepsilon}\]

Finally, \(\mathbf{r}\) is a Gaussian random vector and jointly Gaussian with the function values \(Q(\mathbf{X}_*)\) at any set of query points \(\mathbf{X}_*\):

\[\begin{split}\begin{pmatrix} Q(\mathbf{X}_*) \\ \mathbf{r} \end{pmatrix} \sim \mathcal{N}\left( \begin{pmatrix} m(\mathbf{X}_*) \\ W m(\mathbf{X}_A) \end{pmatrix}, \begin{pmatrix} K(\mathbf{X}_*, \mathbf{X}_*) & K(\mathbf{X}_*, \mathbf{X}_A) W^\top \\ W K(\mathbf{X}_A, \mathbf{X}_*) & W K(\mathbf{X}_A, \mathbf{X}_A) W^\top + \operatorname{diag}(\sigma_1^2, \dots, \sigma_n^2) \end{pmatrix} \right)\end{split}\]

Using the known formula for conditioning a jointly Gaussian vector on one of its blocks, the posterior at the query points is

\[Q(\mathbf{X}_*) \mid \mathbf{r} \sim \mathcal{N}\left(\bar{m}(\mathbf{X}_*), \bar{K}(\mathbf{X}_*, \mathbf{X}_*)\right)\]

with

\[\begin{split}\bar{m}(\mathbf{X}_*) &= m(\mathbf{X}_*) + K(\mathbf{X}_*, \mathbf{X}_A) W^\top \left[W K(\mathbf{X}_A, \mathbf{X}_A) W^\top + \operatorname{diag}(\sigma_1^2, \dots, \sigma_n^2)\right]^{-1} \left(\mathbf{r} - W m(\mathbf{X}_A)\right) \\ \bar{K}(\mathbf{X}_*, \mathbf{X}_*) &= K(\mathbf{X}_*, \mathbf{X}_*) - K(\mathbf{X}_*, \mathbf{X}_A) W^\top \left[W K(\mathbf{X}_A, \mathbf{X}_A) W^\top + \operatorname{diag}(\sigma_1^2, \dots, \sigma_n^2)\right]^{-1} W K(\mathbf{X}_A, \mathbf{X}_*)\end{split}\]

We then can compute the posterior of \(Q(\mathbf{X}_*)\) at any set of query points \(\mathbf{X}_*\).

This operation requires inverting the variance of the observed linear functionals, \(\mathbf{C} = \operatorname{Var}(\mathbf{r})\). As the number of functionals grows this becomes expensive, so we update \(\mathbf{C}^{-1}\) incrementally using Schur complements.

Let the first \(n\) functionals be \(\mathbf{r}_n = \mathbf{W}_n Q(\mathbf{X}_n) + \boldsymbol{\varepsilon}_n\), where \(\mathbf{X}_n\) (previously we referred to this as \(\mathbf{X}_A\), but here the \(n + m\) notation nicely illustrates the stacking of previous and new functionals). Suppose \(m\) new functionals arrive, \(\mathbf{r}_m = \mathbf{W}_m Q(\mathbf{X}_m) + \boldsymbol{\varepsilon}_m\). Their variances and cross-covariance are

\[\begin{split}\mathbf{C}_n &= \mathbf{W}_n K(\mathbf{X}_n, \mathbf{X}_n) \mathbf{W}_n^\top + \operatorname{diag}(\sigma_1^2, \dots, \sigma_n^2), \\ \mathbf{C}_m &= \mathbf{W}_m K(\mathbf{X}_m, \mathbf{X}_m) \mathbf{W}_m^\top + \operatorname{diag}(\sigma_{n+1}^2, \dots, \sigma_{n+m}^2), \\ \mathbf{V} &= \operatorname{Cov}(\mathbf{r}_n, \mathbf{r}_m) = \mathbf{W}_n K(\mathbf{X}_n, \mathbf{X}_m) \mathbf{W}_m^\top,\end{split}\]

so the variance of all \(n + m\) functionals is

\[\begin{split}\mathbf{C}_{n+m} = \begin{pmatrix} \mathbf{C}_n & \mathbf{V} \\ \mathbf{V}^\top & \mathbf{C}_m \end{pmatrix}.\end{split}\]

By the formula for the inverse of a block matrix (Schur complement), we efficiently update \(\mathbf{C}_{n+m}^{-1}\).

\[\begin{split}\mathbf{C}_{n+m}^{-1} = \begin{pmatrix} \mathbf{C}_n^{-1} + \mathbf{C}_n^{-1} \mathbf{V} (\mathbf{C}_m - \mathbf{V}^\top \mathbf{C}_n^{-1} \mathbf{V})^{-1} \mathbf{V}^\top \mathbf{C}_n^{-1} & -\mathbf{C}_n^{-1} \mathbf{V} (\mathbf{C}_m - \mathbf{V}^\top \mathbf{C}_n^{-1} \mathbf{V})^{-1} \\ -(\mathbf{C}_m - \mathbf{V}^\top \mathbf{C}_n^{-1} \mathbf{V})^{-1} \mathbf{V}^\top \mathbf{C}_n^{-1} & (\mathbf{C}_m - \mathbf{V}^\top \mathbf{C}_n^{-1} \mathbf{V})^{-1} \end{pmatrix}.\end{split}\]

Which allows for incremental updates of the inverse without inverting the entire matrix, noting that we have \(\mathbf{C}_n^{-1}\) and the Schur complement \(\mathbf{C}_m - \mathbf{V}^\top \mathbf{C}_n^{-1} \mathbf{V}\) available from the previous step.

Bases: Kernel

Squared-exponential kernel. length_scales length = input dimension. Callable as k(X1, X2).

\[k(X_1, X_2) = \sigma_0^2 \exp\left(-\frac{1}{2} \sum_{d} \frac{(X_{1d} - X_{2d})^2}{\ell_d^2}\right)\]

where \(\ell_d\) is the length scale for the \(d\)-th input dimension.

Parameters:

  • sigma0 (float) – Signal variance.

  • length_scales (list[float]) – Length scales for each input dimension.
