candidate_actions_adaptive(*, z, omega, nk=35, nb=30)[source]¶

Midpoint-rule menu on the feasible \((k', b')\) set at (z, omega).

Nodes are cell centers, so the mesh covers the set exactly:

\[k_i = \underline k + \mathrm{d}k\,(i + \tfrac12), \qquad b_{ij} = \underline b(k_i) + \mathrm{d}b(k_i)\,(j + \tfrac12), \qquad \Delta_{ij} = \mathrm{d}k\, \mathrm{d}b(k_i),\]

with \(\mathrm{d}k = (\bar k - \underline k)/n_k\) and \(\mathrm{d}b(k) = (\bar b(k) - \underline b(k))/n_b\). The \(b'\) span depends on \(k'\), so \(\Delta_{ij}\) varies across slices and \(\sum_{ij}\Delta_{ij} = \sum_i \mathrm{d}k\,(\bar b(k_i) - \underline b(k_i))\).

Parameters:

  • z (float) – Productivity; unused (feasibility depends on omega only).

  • omega (float) – Net worth.

  • nk (int) – Number of \(k'\) cells.

  • nb (int) – Number of \(b'\) cells per \(k'\) slice.

Returns:

(actions, measures) with shapes (N, 2) and (N,).

Return type:

tuple

Menu¶

class src.simulation.environment.menu.Menu(state, actions, measures, points)[source]¶

Bases: object

A quadrature rule over the feasible action set at one state.

Immutable object of action menu at a given state. Immutability allows safe sharing and caching.

Row \(j\) is a cell of the continuous action space, of Lebesgue measure \(\Delta_j\), action \(a_j\) sits at its midpoint. A sum weighted by measures approximates an integral,

\[\sum_j \Delta_j\, g(a_j) \approx \int g(a)\, \mathrm{d}a ,\]

and \(L = \sum_j \Delta_j\) is the Lebesgue measure of the region the menu covers. These are the weights the planner takes as its areas.

Parameters:

  • state (tuple) – The (z, omega) this menu was built at.

  • actions (np.ndarray) – Cell midpoints, shape (N, 2); rows (k', b').

  • measures (np.ndarray) – Cell measures \(\Delta_j\), shape (N,). Equal on a fixed product grid, row-dependent on the adaptive menu.

  • points (np.ndarray) – Menu features, shape (N, d); rows (z, omega, k', b'). Used to query the GP belief. Built from featurized state and action information in the environment.
